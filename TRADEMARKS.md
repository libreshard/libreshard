# The LibreShard name and logo

LibreShard's code is open source under the [Apache License 2.0](LICENSE). The license covers the
code, not the project's identity: section 6 of the license says so explicitly. This page explains
how you can use the **LibreShard** name and the logo (the cyan "L" with the gold button), so that
people always know whether what they install comes from this project.

## You can, without asking

- Say that something works with LibreShard: "a LibreShard shard", "Star Citizen MFD for
  LibreShard", "how I set up LibreShard on my tablet".
- Name LibreShard in articles, videos, talks, reviews and tutorials, and show the logo there to
  refer to the project.
- Redistribute **unmodified** official releases under the LibreShard name, for example in a Linux
  distribution package. Packaging changes (paths, a desktop file) are fine.

## Please ask first

- Distributing a modified version (a fork) under the LibreShard name or with the logo. Forks are
  welcome, but they need their own name and icon, so that bug reports and trust go to the right
  place. Saying "based on LibreShard" is fine.
- Using the name or the logo in the name of a product, company, domain or app store listing.
- Selling merchandise with the logo.

## Never

- Suggesting that the project endorses, certifies or is made by you when it isn't.
- Changing the logo and presenting the result as LibreShard's.

To ask, open an issue or write to hello@libreshard.com.

Names of other programs that appear in LibreShard (Photoshop, Discord, OBS Studio, VS Code…) belong
to their owners. They're only used to say which program a shard works with.
